The game install CullisEngine is developed against. Generated 2026-10-10 from `$FABLE_DIR` (`/home/ross/fable_data`).

## Version

- Fable: The Lost Chapters, European retail DVD (multilingual readmes such as `Czytaj.rtf` and `Leame.rtf`; `banks_dvd.ini`).
- `Fable.exe.cfg` title version: `10000001`.
- `Fable.exe` SHA-256: `41dc91090ae853715ac06d2e9fc96e5d545381d197ed55d624c642f34509ac10`.
- Only English language data is installed (`data/lang/English`).
- Full SHA-256 list: `/home/ross/fable-tlc.sha256` (420 files, outside the repo).

The Steam release may differ. Tests check internal consistency and must not hard-code the sizes or counts below.

## Contents

`data/` is about 2.7 GB in 393 files. The bank, world and region survey generated by `cargo run --release -p fable-data --example survey` is in [survey.md](survey.md).

| `Defs/RetailHeaders/*.h` | Names for bank entries and lipsync | none |
| `Bones/*.bncfg` | Skeleton configs | none |
| `Sound/*.lug`, `*.met`, `*.ogg`; `lang/English/*.lut` | Audio banks, music, dialogue audio | none |
| `Video/*.wmv` | Cinematics | none |
